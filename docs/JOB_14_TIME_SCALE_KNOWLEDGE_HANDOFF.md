# Jurisdiction separation

This job deliberately protects four nearby concepts from collapsing into one vague "time/confusion" layer.

## TEMPORAL ENGINE

Controls **objective narrative/compositional chronology**:

- event order
- recurrence
- loops
- forks
- causal direction
- time windows
- section age
- simultaneous timelines

It does NOT define how time subjectively feels.

That remains ALTERED STATE territory when relevant.

## SCALE ENGINE

Controls:

- what size of object is causally relevant
- what operations exist
- what measurements make sense
- which vocabulary can explain events

It is NOT satisfied by replacing "small" with "big" nouns.

## EPISTEMOLOGY / KNOWLEDGE

Controls:

- who knows which facts
- what evidence exists
- what may be inferred
- what may be disclosed
- how information is acquired
- provenance / uncertainty / proof

It is NOT a personality trait.

## HEADSPACE

Still controls:

- attention
- salience
- working-memory pressure
- interruption
- behavioral tempo
- association

A speaker can therefore have perfectly stable epistemology and chaotic headspace, or perfect attention while possessing almost no information.

# Strong Temporal mechanisms

## REVERSE CHRONOLOGY

Major events are presented latest → earliest.

This is not:

- reversed audio
- generic flashback
- merely retelling the same text backward

Each earlier section must explain or destabilize something already heard.

## LOOP WITH MEMORY

The external section resets.

The performers remember previous passes.

This allows:
- strategy change
- anticipation
- avoidance
- adaptation

while the formal loop remains real.

## LOOP WITHOUT MEMORY

The external section resets.

The performers forget.

The listener remembers.

This creates structural dramatic irony.

## MEMORY ARRIVES BEFORE EVENT

A memory-like account occurs before the event that will later produce it.

When the event finally arrives, the correspondence must be recognizable.

## SECTION AGES FORWARD

A recurring section gets older every time.

Aging may appear through:

- accumulated history
- scars
- institutionalization
- weathering
- simplification
- changed responsibility

not merely "vintage production".

## MISSING INTERVAL

A defined span of chronology is omitted.

Later consequences prove something happened during the gap.

The system reconstructs the missing period from aftermath.

## CIRCULAR CAUSALITY

The ending creates or preserves a condition required by the beginning.

The chronology becomes a closed causal loop.

The mechanisms themselves must still change.

A city is not literally a cell.

The card preserves **structural analogy**, not fake scientific equivalence.

# Strong Epistemology mechanisms

## RECONSTRUCTING FROM EVIDENCE

The narrator does not directly know what happened.

The song must separate:

- observation
- inference
- confidence
- contradiction
- missing evidence

## PROCEDURE / NOT PURPOSE

The speaker can execute every step correctly.

They cannot explain:
- why the process exists
- who designed it
- what success ultimately accomplishes

This can combine very effectively with bureaucracy / training / service Reality layers.

## LISTENER KNOWS MORE THAN SPEAKER

The system creates structural dramatic irony.

Nothing requires the speaker to become confused.

They are simply operating from a smaller information set than the audience.

## CLASSIFIED / REDACTED

The fact may be known internally.

The rule restricts disclosure.

The generator must create real informational holes through:

- silence
- redaction
- euphemism
- codes
- permission boundaries

## OBSERVATION CREATES THE FACT

A selected variable remains unresolved until measured.

Observation then produces a state transition.

This is a creative structural mechanism, not a general scientific claim about all observation.

## MEASUREMENT DESTROYS THE EVIDENCE

Learning has a cost.

Every test irreversibly changes or consumes the thing being tested.

## SENSORS DISAGREE

Multiple measurement channels report incompatible states.

The system must:
- compare
- calibrate
- triangulate
- revise the model

rather than arbitrarily selecting one sensor.

## BLACK BOX SYSTEM

Inputs and outputs are visible.

Internal mechanism is inaccessible.

The composition learns by experiment.

## WHITE BOX / UNKNOWN PURPOSE

All mechanics are visible.

Intent remains unknown.

Mechanistic transparency therefore does not magically reveal purpose.

## METADATA ONLY

Content is unavailable.

The system may know:
- sender
- timestamp
- size
- duration
- route
- count
- location-like traces

but it cannot silently invent the hidden message.
