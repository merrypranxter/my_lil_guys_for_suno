# Generative Physics Build Plan

This plan turns the idea vault into playable one-click Lil Guys whole-stack presets without flattening the app into a conventional preset browser.

## Phase A — Prompt-native specialty presets
Goal: ship immediately playable one-click stacks using the existing Minds + Composition Lab + Music Seed compiler.

Jobs:
1. **MOUTH OPERA** — COMPLETE
2. DETROIT ASSEMBLY-LINE POSSESSION
3. BLUEGRASS PARTICLE ACCELERATOR
4. LOOSE-MOUTH POCKET MONSTER
5. RUBBER-THROAT FUNK CABARET
6. OPERA IN A TOOL SHED
7. THE CHOIR HAS UNIONIZED

Each job must:
- create or reuse executable Music Seed mechanisms;
- create a dedicated Music Seed recipe;
- create a Specialty Whole-Stack preset with Minds, Composition engines, instruments/sources, and calibrated controls;
- leave Reality Engines empty unless the law actually needs one;
- obey Composition dimension limits;
- add verification.

## Phase B — Lyric physics
Goal: make lyric behavior independently selectable rather than smuggling it into genre/style.

Initial engines:
- FALSE LIMERICK
- ROUND / CANON
- MUTATING CANON
- MULTI-CLOCK ROUND
- DEADWOOD MOUTH
- PROFANITY AS PUNCTUATION
- SEMANTIC DEBT
- WORD EXTINCTION
- PARASITIC LYRIC FORM

This likely deserves a dedicated lyric-law schema rather than hard-coding behavior into specialty presets.

## Phase C — Prompt-native generative physics
Goal: laws that produce music as their consequence.

Initial set:
- SIR MOTIF EPIDEMIC
- LRU NOTE CACHE
- M/M/1 MUSICAL BOTTLENECK
- DOUBLE-ENTRY ENERGY LEDGER
- ITERATED PRISONER'S DUET
- TELEOLOGICAL BOOTSTRAP SONG
- VALID-BUT-WRONG MAXIMIZER
- MISSING FUNCTION
- TECTONIC SUBDUCTION
- BATESON DOUBLE BIND

## Phase D — Stateful controllers
Goal: Lil Guys keeps real history instead of asking the model to pretend a ledger exists.

Initial set:
- SCAR-TISSUE CHORUS / MEMORY RECONSOLIDATION
- SILENCE ECONOMY
- MUSICAL IMMUNE SYSTEM
- RUMOR NETWORK
- DARWIN'S SHITTY LITTLE VERSE
- WORD EXTINCTION counters
- LRU cache state
- cooperation/defection history
- motif infection/immunity state

## Phase E — Generative-physics UI
Goal: distinguish starting configurations from laws.

Planned UI concepts:
- Recipe vs Generative Physics badges
- PROMPT-NATIVE / STATEFUL / AUDIO-NATIVE implementation badges
- threshold/phase-change knobs
- WRONGNESS INSIDE VALIDITY
- AUTOIMMUNITY
- CACHE SIZE
- TRANSMISSION R0
- FORGIVENESS
- SILENCE VALUE
- GENERATIONAL DRIFT

Do not require the user to understand the taxonomy before playing. One-click remains sacred.

## Phase F — Audio-native / stem engine
Goal: literal execution for mechanisms that cannot honestly be performed by prompt text alone.

Parking-lot candidates:
- literal auditory moiré / stem-phase misregistration
- packet loss + retransmission
- reaction-diffusion spectral carving
- GLSL-to-audio
- effect-bus supply-chain latency
- proof-of-work playback gates
- observation-crystallized interactive regeneration
- repeated model-collapse lineage
- lossy stem collision/reconstruction
