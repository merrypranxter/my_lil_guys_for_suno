# Starter Texture / Sensory Seeds

## Goal

Texture seeds convert sensory adjectives into **audible operating rules**.

A texture seed must not merely say "make it glittery / wet / chrome / analog." It must specify what changes in:

- transient shape;
- envelope;
- spectral behavior;
- articulation;
- local ambience;
- spatial placement;
- distortion / saturation;
- event density;
- source separation.

Texture seeds own texture/production jurisdictions only. They do not decide the song subject, world, genre, or emotional valence.

## Operational examples

### GLITTERING

Not "sparkly."

It means:

- short bright micro-transients;
- fast decay;
- discrete stereo scattering;
- particle density increases before tail length;
- minimal shared wash.

### RUBBERY

Not "bouncy vibe."

It means:

- compressed attacks;
- elastic pitch/filter rebound;
- damped oscillation after impact;
- dry reference layers so deformation stays measurable.

### CHROME

Not "shiny."

It means:

- hard bright transient;
- compact metallic reflection;
- finite tail;
- negative space around reflective events.

### STICKY

Not "gooey."

It means:

- selected releases overstay the next event;
- short residue/retriggers attach to following attacks;
- dry actors remain present as contrast;
- base pulse stays measurable.

### CHEAP ANALOG

Not a master-bus nostalgia filter.

It means selective:

- cassette/tape instability;
- local hiss;
- spring resonance;
- saturation;
- bandwidth restriction;
- wow/flutter.

Damage belongs to particular sources or sections so arrangement detail survives.

### HYPER-CLEAN IMPOSSIBLE OBJECT

Not generic expensive polish.

It means:

- surgical source isolation;
- almost no shared ambience;
- extreme transient precision;
- physically impossible envelope behavior;
- impossible acoustic behavior remains sharply legible.

## Stacking

Multiple texture seeds may be active at once.

If they claim the same jurisdiction, the existing Starter collision compiler forces explicit negotiation instead of averaging.

Example:

**GLITTERING + CHROME + TOYBOX PHYSICAL**

should resolve as separate populations / registers / event types, not "somewhat shiny quirky production."

## Relationship to instruments

Texture seeds do not select instruments.

Instrument Packs decide **what physical sound sources exist**.

Texture seeds decide **how selected sound sources behave at their surfaces**.

That means:

**WRONG ENSEMBLE PIT #2 + RUBBERY + CHROME**

can make the same eight-source ensemble behave very differently without replacing the eight sources.

## Relationship to favorites

Texture seeds use the same Starter Favorites Intelligence as every other Starter category.

Explicit **MORE LIKE THIS / LESS OF THIS** feedback can softly bias future Texture rerolls.

Manual selection always wins.
